## Коммерческая логика
Пока цены отображаются как «по запросу», чтобы не публиковать неподтверждённый прайс. Доставка, монтаж и гарантийные сроки фиксируются после расчёта и выбора конкретного оборудования.

## Перед публичным запуском
1. Утвердить постоянное название бренда и логотип.
2. Утвердить телефон / WhatsApp / Telegram / email или CRM для реальной отправки заявок.
3. Утвердить розничные цены и стоимость монтажа.
4. Заменить временные визуальные материалы на собственные или разрешённые товарные изображения.
5. Создать отдельный GitHub-репозиторий и перенести ветку `solar-stations-site`.
6. Подключить GitHub Pages / хостинг и отдельный домен.
